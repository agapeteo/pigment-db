# Project Instructions

## Test-Driven Development

Use test-driven development with a RED–GREEN approach for every issue and feature:

1. Write one behavior-focused test before changing production code.
2. Run the test and confirm that it fails for the expected reason (RED).
3. Implement the minimal feature or fix needed to satisfy the test.
4. Run the test and confirm that it passes (GREEN), then run the full relevant test suite.

Repeat this cycle one behavior at a time. Refactor only while the tests are GREEN, and rerun the tests after each refactor.
