## Continued remediation

The candidate now has one lock acquisition but still allocates and zero-initializes a new V2 envelope for every mutation, copies the payload into it, and calculates an unused payload-only CRC before calculating the authoritative envelope CRC. These costs are most visible in the simpler key/value and key/set operations; map work masks them.

Continue under this failed performance gate as RED evidence:

1. Reuse one frame buffer owned by the already-exclusive WAL state.
2. Encode sequentially into initialized bytes without unsafe code or a zero-fill pass.
3. Defer the legacy payload CRC unless the acquired format is actually legacy; V1/V2 rely on their versioned envelope CRC.
4. Preserve byte-exact legacy output and all V2 replay/corruption behavior, then run the unchanged Protocol V5 gate.
